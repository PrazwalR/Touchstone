| Field | Value |
| --- | --- |
| Experiment | E2, trigger recall (spec §16.4); decides gate G1 (spec §20.1) |
| Label | historical backtest |
| Hypothesis | The trigger E1 selected catches at least the pool's break-even share of toxic markout on held-out data while flagging at most 30% of swaps |
| Chain, pool, fair price, markout, toxic markout, reference, trigger rules | As in E1.md, unchanged |
| Trigger | The one E1 selected on the development window. E2 refuses to run if E1 was produced by different analysis code |
| Held-out window | 2026-09-27 00:00 UTC to 2026-10-25 00:00 UTC (28 days) |
| Primary metric | Held-out recall r = flagged toxic markout / all toxic markout |
| Break-even | r* = (sum of m) / (alpha * sum of toxic markout) on the held-out swaps, alpha = 0.80. This is spec §4.6's r* = (L - F) / (alpha (L - (f + eps) s)) measured directly: the numerator is LPs' net markout loss after fees, the denominator alpha times the markout above fee and margin. Both at Delta = 3 s |
| Pass or kill line | **Pass** if held-out r >= r* and held-out phi_count <= 0.30. **Kill** otherwise (spec §16.4, verbatim: "Kill if held-out recall is below break-even at phi <= 0.30") |

| If r* <= 0 | LPs did not lose at 3 s on this pool and window; the verdict is reported as pass with that caveat, and the 15 s variant is the one to read |
