The current code is a detection sensitivity model. Its test fixtures are synthetic unit tests, not an E5 result. The contract's overshooting ITM approximation and cap/exact-output accounting remain release risks outside this model. A corrected reference-time tape must get a new preregistration rather than being substituted into frozen E1/E2.

The registered inputs are the E5 subset of `results/E2.json` source hashes. The complete sensitivity grid is in `config/E5.json`.
The selected E1 trigger uses USDC base units. Virtual blocks are 12 seconds, with delays of zero, one or two slots. Ties retain tape order. The E2 historical backtest gives r* = −0.3118807034660406. Recall is nonnegative, so this pool cannot distinguish evasion strategies by that kill line alone. Report each recall and its interval.
