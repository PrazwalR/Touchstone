# E1 pre-registration: markout census and trigger calibration

Status: **frozen 28 October 2026**, before any swap data for the window was downloaded. Changing any field
below means a new file and a new name, and both results are reported (spec §16.6).

| Field | Value |
| --- | --- |
| Experiment | E1, markout census (spec §16.4) |
| Label | historical backtest |
| Hypothesis | Descriptive. Toxic markout concentrates in the first swap of a block, in large swaps, and in swaps that trade toward the reference |
| Chain and pool | Ethereum, Uniswap v3 USDC/WETH 0.05% (`0x88e6A0c2dDD26FEEb64F039a2c41296FcB3f5640`) |
| Development window | 2026-08-30 00:00 UTC to 2026-09-27 00:00 UTC (28 days). E1 reads only this window |
| Held-out window | 2026-09-27 00:00 UTC to 2026-10-25 00:00 UTC (28 days); used only by E2 |
| Fair price | Binance ETHUSDT 1 s close divided by USDCUSDT 1 s close, from the public daily dumps, each verified against Binance's SHA-256. The price standing at time t is the close of the candle that opened at t - 1 s; seconds without a candle carry the last close |
| Swap time | The block timestamp, from the `blockTimestamp` field of each Swap log |
| Markout | m = x_r * P*(t + 3 s) + x_q in USDC base units, from the trader's side of the Swap amounts (fee included). Positive means LPs lost m. Delta = 3 s is the spec §14.2 default |
| Toxic markout | max(0, m - eps * N), eps = 2 bps, N = abs(x_q) (spec §4.6) |
| Reference for drift | Chainlink ETH/USD AnswerUpdated logs from every aggregator behind proxy `0x5f4eC3Df9cbd43714FE2740f5E3616155c5b8419`; the answer is the latest log at or before the swap's block, ignored when older than 3,960 s (heartbeat + 10%) |
| Trigger rules | Exact ports of TriggerLib, FlowBucketLib and PriceLib.signedGapBps (`tsr/triggers.py`), checked against the contracts by `contracts/test/differential/TriggerPort.t.sol` |
| Census outputs | Swaps, volume, net LP markout and toxic markout; toxic share by block position (first swap on the pool in the block vs later), by size ($0-1k, 1k-5k, 5k-25k, 25k-100k, 100k-500k, 500k+), by signed drift (<=0, 0-2, 2-5, 5-10, 10-20, 20+ bps) |
| Calibration grid | N0 in {1k, 2.5k, 5k, 10k, 25k, 50k}; N_min in {50k, 100k, 250k, 500k} with N_min >= N0; h in {6, 12, 24, 60} s; tau in {2, 5, 10, 20} bps |
| Selection rule | Highest development recall subject to development phi_count <= 0.30; ties to lower phi_count, then larger N0. Recall = flagged toxic markout / all toxic markout. phi_count = flagged swaps / all swaps |
| Pass or kill line | None: descriptive. Its output, the selected trigger, is the only input E2 takes from the development window |
| Analysis code | SHA-256 `40041d0c9d7e078aacce4a1aeee36135bc6fe385304b6db08d36b08135de64c6` over the files listed in `experiments/common.py` ANALYSIS_FILES, in that order |
| Input datasets | Hashed at run time and written to `results/E1.json` |
| Random seed | Not used by E1 |
| Excluded | The window's first swap (no known pre-swap price) |
