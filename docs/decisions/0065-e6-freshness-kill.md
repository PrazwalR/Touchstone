# 0065 E6 freshness kill

Record the frozen E6 simulation as a kill. All 21 configurations exceeded the target ratio of 1.10 in development and held-out evaluation. The held-out ratios ranged from 1.3923 to 1.7331. Cases with ε equal to hedging cost also crossed the line. The complete grid, both windows and bootstrap intervals are in the [results write-up](../../research/results/README.md).

The result is evidence about the registered constant-product model, including its fixed trade-size grid, one agent and retention on all modeled arbitrage. It does not measure LP returns or testnet economics. Retain the thresholds and the failed run. Any mechanism response or differently scoped follow-up requires an owner decision and its own preregistration. M11 and the release remain open.
